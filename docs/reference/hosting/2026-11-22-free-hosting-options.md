# Free-tier hosting options for Simplex (researched 2026-11-22)

App constraints: Next.js 14.2.35 App Router (server components, API routes, middleware), Node runtime, Prisma + PostgreSQL, commercial product (POS for Rwandan retailers), stable HTTPS hostname, tolerable latency from Rwanda, cold starts OK.

Method: provider docs and terms pages fetched 2026-11-22. Where a page did not state a commercial-use rule either way, that is flagged "NOT CONFIRMED" and is not a permission. "No prohibition found" means I read the terms/pricing/docs and found no ban, which is weaker than an explicit grant.

## Bottom line

No fully free stack exists where every layer has commercial use affirmatively confirmed in writing. The one app host with an explicit written grant is **Netlify Free** ("you can deploy commercial projects"), but on Free it runs functions in US-East (Ohio) only, and it hard-pauses the whole site when the 300 monthly credits run out. The Postgres with the best technical fit is **Neon Free** (direct and pooled endpoints, Frankfurt region, 1 GB/project), but its terms and docs are silent on commercial use and call the plan "Prototypes, side projects, and small teams" (NOT CONFIRMED). Free is therefore fine for a pilot and a poor base for paying customers: a paused site or a 30-day-expiring database is an outage for a till. The proper answer is about **$13/month on Render (Frankfurt web $7 + Postgres $6)** or about $5-10/month on Railway; see the cost section. Recommendation: app = Netlify Free for a pilot only, otherwise a paid always-on host; Postgres = Neon (free for pilot, Launch pay-as-you-go for production).

## Options that look free but are not, for us

- **Vercel Hobby**: Terms restrict Hobby to "personal or non-commercial use". Our product is commercial, so using it breaches the ToS and risks removal of the deployment. https://vercel.com/legal/terms
- **Cloudflare Workers/Pages**: OpenNext no longer supports Next 14 (needs 15 or 16), and Free Services may not carry card payment data (not a concern if all payments are mobile money, but a clause to check with finance). https://opennext.js.org/cloudflare ; https://www.cloudflare.com/terms/
- **Render Free (web and DB)**: Docs say not for production; the DB deletes itself 30 days after creation; the web service sleeps 15 minutes. https://render.com/docs/free
- **Railway Free**: $1/month, sleeps, no custom domain, no region choice. https://docs.railway.com/pricing/free-plan
- **Fly.io and Koyeb**: No free tier for new accounts. https://docs.fly.io/about/pricing ; https://www.koyeb.com/blog/koyeb-is-joining-mistral-ai-to-build-the-future-of-ai-infrastructure
- **AWS and GCP trial credits**: Time-boxed (AWS 6 months; GCP $300/90 days). Cloud Run's monthly free quota is durable but the database is not free (Cloud SQL is a 30-day trial). https://aws.amazon.com/free/ ; https://docs.cloud.google.com/free/docs/free-cloud-features
- **Azure F1**: 60 CPU-min/day, no SLA/production support. https://azure.microsoft.com/en-us/pricing/details/app-service/linux/
- **Hugging Face Spaces, Glitch, Tembo**: Docker Spaces need a paid plan; Glitch and Tembo Cloud are shut down. https://huggingface.co/docs/hub/en/spaces-overview ; https://blog.glitch.com/post/goodbye-glitch
- **Oracle Always Free**: Technically free and always on, but self-managed, home-region-bound, reclaimable when idle, and the allowance was halved without notice in June 2026. https://www.infoq.com/news/2026/07/oracle-cloud-free-tier-limits/
- **Supabase/Aiven/Neon free DBs for production**: They pause or power off when idle (Supabase 1 week, Aiven after inactivity, Neon after 5 min) and none offers a backup/SLA you could rely on for paying shops. Sources in the Postgres table.
